# 来源与版本说明

本 Skill 的规则来自三类来源：通用 Humanizer 规则、VibeHub 中文 AI 口癖整理、大学生创新创业/学术科技竞赛公开规则，以及“可信卫士”项目既有写作约定。

## 1. Humanizer-zh

- Repository: https://github.com/op7418/Humanizer-zh
- Base file: `SKILL.md`
- License: MIT
- 本 Skill 只吸收和改写其检测思路，并针对正式中文竞赛文档重新约束；不采用“为了像人而主动加入跑题、情绪、第一人称”等不适合技术材料的做法。
- 原项目 MIT 许可信息见根目录 `THIRD_PARTY_NOTICES.md`。

## 2. VibeHub《防止 AI 味儿》

- URL: https://vibe-hub.org/anti-ai-flavor
- 参考内容：中文口癖类条目，包括安抚式客服腔、单字动作、滥用双引号、夸张比喻、无依据提升立意、咨询黑话、夸奖读者、“不是 X，而是 Y”、固定开场、过度分点和聊天式结尾等。
- 本 Skill 对这些内容进行了概括和竞赛文档适配，不复制页面大段原文。

## 3. 中国国际大学生创新大赛

设计本 Skill 时参考：

- 教育部《中国国际大学生创新大赛（2026）的通知》：https://www.moe.gov.cn/srcsite/A08/s5672/202607/t20260731_1445670.html
- 公开转载的《中国国际大学生创新大赛（2025）评审规则》。近年高教主赛道常见评审维度包括个人成长、项目创新、产业/社会价值、团队协作。

2026 通知特别强调参赛资格、成员实质性贡献，以及科技成果、知识产权、财务、运营、荣誉奖项等材料的真实性与合规性。因此本 Skill 将“不得润色出虚假状态”设为硬约束。

## 4. 挑战杯

设计本 Skill 时参考“挑战杯”全国大学生课外学术科技作品竞赛公开章程与评审规则。科技作品评审长期重视科学性、先进性、现实意义；科技发明制作还关注应用价值和转化前景。

官方网站：https://www.tiaozhanbei.net/

## 5. 时效性

竞赛规则会随届次、赛道、组别调整。`competition-writing-guide.md` 只保存稳定的写作原则，不把某一届分值永久写死。

当用户明确要求匹配某届赛事时：

1. 核对比赛全名、年份、赛道/组别；
2. 如具备联网能力，优先获取当届官方通知或评审规则；
3. 用最新规则覆盖本 Skill 中的通用框架；
4. 不根据旧规则臆测新规则。
